# Security and Privacy

## Reporting vulnerabilities

After a public repository exists, use its private security-advisory channel for
vulnerability reports. Do not paste sensitive review data into a public issue.

## Data handling

Analysis is local and makes no network requests. Input and output can contain
personal data copied from reviews, so reports are written with owner-only
permissions where the operating system supports them. Sanitize reproductions
before sharing them publicly.

The repository's examples are synthetic and contain no platform credentials,
cookies, API tokens, or real hotel review records.
